# QuantDesk · A 股 AI 量化研究系统

QuantDesk 是一个基于 Streamlit、DeepSeek、AkShare 和 Backtrader 的 A 股量化研究应用。用户输入股票代码和 DeepSeek API Key 后，系统会依次完成市场调研、新闻分析、策略生成、有限迭代回测和独立风险控制，并输出可审计的研究报告。

> 本项目仅用于量化研究与学习，不构成投资建议，不会自动下单。历史回测不代表未来收益。

## 主要功能

- **市场数据调研**：获取 A 股前复权日线，计算趋势、波动率、RSI、ATR、流动性和相对强弱等指标。
- **新闻分析**：由 DeepSeek 对公开新闻进行事件分类、情绪评分和影响分析；新闻正文只作为不可信数据处理。
- **策略生成**：生成结构化的趋势或均值回归策略，并通过 Pydantic 校验参数范围。
- **有限迭代回测**：最大迭代次数限制为 1～5 次，按时间顺序划分训练集、验证集和留出集。
- **历史交易记录**：展示历史买卖时间、价格、交易原因和收益表现。
- **当前条件信号**：输出条件买入、卖出、观望或风控阻断，并给出对应条件和参考价格。
- **独立风险控制**：买入风控与卖出退出分离，风控阻断不会阻止降低风险的退出操作。
- **可视化日志**：实时展示各阶段进度、耗时、异常和迭代结果。
- **报告导出**：支持下载完整 JSON 研究报告，报告不包含 API Key。
- **Key 本地保存**：可选择使用 Windows DPAPI 当前账户加密保存 DeepSeek API Key，下次启动自动加载。

## 技术栈

- Python 3.11
- Streamlit
- DeepSeek API（`deepseek-chat`）
- AkShare
- Backtrader
- Pandas / NumPy
- Pydantic

## 数据来源

| 数据 | 默认来源 | 备用策略 |
| --- | --- | --- |
| A 股前复权日线 | 新浪财经 | 自动切换腾讯证券 |
| 沪深 300 基准 | 新浪财经 | 获取失败时降级为暂无，不阻断主流程 |
| 个股新闻 | 东方财富公开新闻 | 获取失败时标记新闻证据不足 |

不同来源的数据不会被混拼为同一段前复权历史。公开数据源可能出现限流、字段变化或临时不可用。

## 快速开始

### 1. 克隆项目

```powershell
git clone https://github.com/xzndsg/quantdesk.git
cd quantdesk
```

### 2. 创建虚拟环境

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```powershell
python -m pip install -r requirements.txt
```

### 4. 启动系统

```powershell
streamlit run app.py
```

浏览器访问：`http://localhost:8501`

## 使用流程

1. 输入 6 位 A 股代码，例如 `000001`。
2. 输入有效的 DeepSeek API Key。
3. 如需持久保存，点击“保存 Key”；也可以不保存，仅用于当前会话。
4. 设置最大迭代次数（1～5）。
5. 按需展开高级参数，配置初始资金、历史年限和风险偏好。
6. 点击“开始分析”，在页面查看实时进度与日志。
7. 在交易信号、市场调研、新闻分析、策略回测、风险控制和运行日志标签页查看结果。
8. 点击“导出研究报告”下载 JSON 报告。

### API Key 保存说明

点击“保存 Key”后，系统使用 **Windows 当前账户 DPAPI** 加密凭据，保存到：

```text
%USERPROFILE%\.quantdesk\deepseek.json
```

凭据不会保存在项目目录，也不会进入日志、报告或 Git 提交。其他 Windows 账户无法直接解密当前账户保存的凭据。

## 回测与迭代逻辑

- 历史数据按时间顺序划分为 **60% 训练集、20% 验证集、20% 留出集**。
- 候选策略在训练集和验证集上评估，最佳验证策略最后在留出集上评估。
- 留出集不参与候选策略选优，降低数据泄露和过拟合风险。
- 回测考虑 100 股整手、佣金、滑点、ATR 止损和止盈。
- 达到验证指标条件或连续两轮无改善时提前停止。
- 最大迭代次数始终限制在 1～5 次。

## 信号含义

| 信号 | 含义 |
| --- | --- |
| 条件买入 | 技术条件满足且风控允许，仍需人工确认，不会自动下单 |
| 卖出 / 退出 | 策略触发退出条件；无持仓时无需执行卖出 |
| 继续观望 | 当前没有满足条件的交易机会 |
| 风控阻断 | 硬性风险项禁止新增买入，但不阻止卖出降险 |

## 项目结构

```text
quantdesk/
├── app.py                    # Streamlit 单页界面与交互
├── requirements.txt          # Python 依赖
├── .streamlit/
│   └── config.toml           # 页面主题配置
└── quant_system/
    ├── ai.py                 # DeepSeek 新闻分析与策略生成
    ├── backtest.py           # Backtrader 回测与交易记录
    ├── credentials.py        # Windows DPAPI 凭据存取
    ├── engine.py             # 流程编排、有限迭代与日志
    ├── market.py             # 行情、新闻和技术指标
    ├── models.py             # Pydantic 结构化模型
    └── risk.py               # 独立风控与当前交易信号
```

## 安全与使用限制

- 不要将真实 API Key 写入源码、`.env` 或提交到公开仓库。
- DeepSeek 调用需要有效 Key、可用额度和网络连接。
- 公开行情及新闻接口仅用于研究，生产环境建议替换为有服务保障的数据源。
- 回测结果依赖历史数据、策略假设和交易成本设置，不代表未来表现。
- 系统不提供自动实盘交易功能。
